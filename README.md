One out-of-office auto-reply, at most 120 characters, written as if a houseplant sent it: a fern last watered in March that now answers email on the same schedule it gets watered — never — and refers anything urgent to the cactus, which cares even less.

## Run it

```sh
python3 main.py  # writes the line to /output/entry.txt
```
